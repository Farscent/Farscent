I'm building my foundations in data cleaning, exploratory analysis, statistics, and machine learning. I'm also interested in stocks and capital markets, including how to analyze price movements, returns, and risk.

- **Python:** readable functions, file handling, input validation, and testing.
- **Data analysis:** pandas, NumPy, visualization, and explaining results clearly.
- **Machine learning:** simple baselines, train/test splits, regression, and evaluation.
- **CRISP-DM:** connecting a clear question to data preparation, analysis, and useful findings.
- **Capital markets:** moving averages, price returns, volatility, and drawdown.
